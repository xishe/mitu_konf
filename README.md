# mitu_konf — оценка критериев и альтернатив (взвешенная сумма)

Веб-приложение на **Flask** для многокритериальной оценки альтернатив методом **взвешенной суммы (SAW / Simple Additive Weighting)**: пользователь задаёт критерии, их веса и оценки альтернатив по каждому критерию — приложение считает итоговую полезность каждой альтернативы и позволяет их сравнить.

## Как это работает

1. Через веб-форму вводятся:
   - названия и веса критериев (`criteria_names`, `criteria_weights`);
   - названия альтернатив (`alternative_names`);
   - оценки каждой альтернативы по каждому критерию (`alternative_scores`).
2. Итоговая полезность альтернативы считается как скалярное произведение вектора её оценок на вектор весов критериев (`Σ score_i × weight_i`).
3. Альтернативы с посчитанной полезностью выводятся на странице для сравнения.

По умолчанию (без отправки формы) показывается пример-заготовка — сравнение источников энергии (солнечная, ветровая, гидро-, биомасса, ядерная) по шести критериям: экономическая эффективность, экологическая устойчивость, надёжность и доступность, гибкость и адаптивность, техническая интеграция, социальная ответственность.

## Стек

- Python 3
- [Flask](https://flask.palletsprojects.com/) — веб-сервер и шаблонизация (`templates/index.html`)
- NumPy — вычисления

## Установка

```bash
git clone https://github.com/xishe/mitu_konf
cd mitu_konf
pip install flask
pip install numpy
```

## Запуск

```bash
python main.py
```

Приложение будет доступно по адресу:

```
http://127.0.0.1:5000/
```
